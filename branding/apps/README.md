# App icons

One icon family for the suite, grown from the Omnibloom swirl. Each folder holds the exported files:

| File | Use |
| --- | --- |
| `icon0.png` | 512×512 opaque PS5 tile icon (titles only: Omni today) |
| `pic0.png`, `pic1.png` | 1920×1080 PS5 tile backgrounds (titles only) |
| `icon-256.png` | App icon for ID cards, the start page and the Bloom Core status page |
| `favicon.png`, `favicon.ico` | Web pages |
| `setup.ico`, `setup.icns` | Omnibloom Setup on Windows and macOS (in `setup/`) |

Master Control's icons live in its own repository. The editable SVG sources are kept with the design files, not here (they embed the large brand PNG).
