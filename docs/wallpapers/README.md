# Omnibloom wallpaper collection

Fifteen existing original Omnibloom universe artworks, exported in three sizes each: desktop 3840×2160, phone 1080×1920 and phone 1440×3200. Set an image using your operating system's wallpaper controls; this archive does not modify any device settings.

Sources: sibling 20261102-universe-art and 20261102-r2-universes art folders, originally generated for this project. Their original prompts/source assets remain in those folders. Manifest records exact source dimensions and SHA-256 hashes. Exports use a centred crop and Lanczos resize, with no invented detail or claim of native 4K source resolution. Phone versions intentionally crop the sides. All JPEGs are RGB with no source metadata copied.
