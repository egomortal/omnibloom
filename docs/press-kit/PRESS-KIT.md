# Omnibloom press kit

Reviewed 2026-11-03. Editorial assets and copy for the Omnibloom project; no publication performed.

## Description — one sentence

Omnibloom brings a controller-friendly browser, controller tools and connected homebrew utilities together for PlayStation 5.

## Description — short

Omnibloom is a homebrew software suite for PlayStation 5, built around a readable, controller-first interface. Omni is its browser, Master Control provides controller tools, and Bloom Core connects participating apps through shared settings and intents. The project explores practical local utilities and original visual themes. Availability depends on the release, console firmware and supported homebrew environment; preview designs should not be described as shipped features.

## Description — extended

Omnibloom brings a browser and related homebrew tools into a consistent experience designed for a television and a controller. The suite uses large text, visible focus and shared visual settings to make everyday navigation easier from the couch. Omni is the browser, Master Control is the controller app, and Bloom Core is the service connecting participating apps.

The project's interface work includes original navigation universes, optional ambient scenes and useful local tools. The screenshots in this kit are explicitly labelled browser prototypes, not evidence of a released console build. Release notes remain the source for available features, supported firmware and installation requirements. Omnibloom is an independent homebrew project and is not affiliated with or endorsed by Sony Interactive Entertainment. Do not infer compatibility with every console or website from an interface preview.
