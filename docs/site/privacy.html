Keep control close.

This page describes the intended suite design; the release owner must verify it against the shipped build.

Local app discovery

Bloom Core helps installed apps find each other on the console. Web pages do not receive its token. A verified app record determines which pages the browser can reach.

Sites still receive visits

When you visit a website or start a download, that service receives the request and applies its own privacy policy. A local interface does not make browsing anonymous.

History, saved links and passwords

These features may keep data on the device. Storage, encryption, retention and deletion behaviour must be documented for the final build. Do not publish an encryption or no-telemetry claim until verified.

Support logs

Review logs before sharing them. Remove account details, cookies, tokens, personal file names and private URLs. Sharing a screenshot should be your choice.

Console block

The browser restricts website access to local console services. Ask maintainers to review a legitimate app integration rather than turning off the protection.
