Printable manual

Questions, answered.

Does it replace the console system?

No. Omnibloom is a set of homebrew apps. Setup manages suite components; it is not a system update.

Will every streaming site work?

No. Browser compatibility varies. Protected media can require a supported content decryption module and service approval. Omnibloom does not bypass DRM.

Do I need Bloom Core open?

Bloom Core runs in the background. Apps should still open with their own defaults if it is unavailable; shared discovery and actions may be limited.

Can I use another controller?

Check the controller table for the exact model, connection type and verified release. A family name alone is not a compatibility guarantee.

Why is a local page blocked?

The console block limits which local services web content can reach. Installed app pages are allowed only through verified app records. Do not disable the block to fix a page.

Is JDownloader 2 included?

Setup has an optional JDownloader 2 step. Availability and redistribution terms must be checked for the shipped release; it remains a separate project.

Where is Ex-Box 360?

It is planned for later and is not part of this launch promise.
