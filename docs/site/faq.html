Release review · 3 November 2026. These guides describe the candidate suite. Check the final release notes for supported firmware, package links and accepted features. JIT and GPU features remain experimental and off by default. Ex-Box 360 remains Coming soon.

Questions, answered.

Does it replace the console system?

No. Omnibloom is a set of homebrew apps. Setup manages suite components; it is not a system update.

Will every streaming site work?

No. Browser compatibility varies. Protected media can require a supported content decryption module and service approval. Omnibloom does not bypass DRM.

Do I need Bloom Core open?

Bloom Core runs in the background. Apps should still open with their own defaults if it is unavailable; shared discovery and actions may be limited.

Can I use another controller?

Check the controller table for the exact model, connection type and verified release. A family name alone is not a compatibility guarantee.

Why is a local page blocked?

The console block limits which local services web content can reach. Installed app pages are allowed only through verified app records. Do not disable the block to fix a page.

Is JDownloader 2 included?

Setup has an optional JDownloader 2 step. Availability and redistribution terms must be checked for the shipped release; it remains a separate project.

Where is Ex-Box 360?

It is planned for later and is not part of this launch promise.

Does a desktop test mean the console release is ready?

No. The tested pages and local examples help catch interface problems, but they do not prove console compatibility, video playback or native service behavior. Use only the accepted release and its exact requirements.

Is the PC test rig a finished console simulator?

No. The PC rig now builds the same WebKit source snapshot as Omni and has completed a bounded 30-minute software-rendered run. It still lacks full Omni patch parity and accepted calibration. Earlier approximation tests, including tighter-memory failures, remain separate evidence.

Why are verified downloads still pending?

Native integration and package acceptance remain open. The release also needs outstanding component licences and attribution checked. A successful interface test does not clear those requirements.

Universe and Sleeve previews

Fifteen Universe start layouts are available as local proposals. Each changes the arrangement and presentation of the same actions. Arrange supports panel swaps with Undo and Reset; a separate Sleeve preview supports custom positions and sizes for the actual Apps, Pins and Recents panels. Native persistence and integration across other app screens remain pending.
