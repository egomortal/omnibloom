Release review · 3 November 2026. These guides describe the candidate suite. Check the final release notes for supported firmware, package links and accepted features. JIT and GPU features remain experimental and off by default. Ex-Box 360 remains Coming soon.

Built with others.

Omnibloom stands on open-source work shared by many people. Thank you.

Controllers (Master Control)

  • PadBridge PS5 by X-F1REBALL-X — the payload Master Control starts from.
  • Ghost-Control v5 by StonedModder — the Switch Pro, 8BitDo, Manba, HORI and XIM USB drivers.
  • NikoBellikJR31 — the Manba V2 patch for Ghost-Control.
  • AnyPad-PS5 by elmonomalvad0 and ps5-wireless-pads by AngelLopezTorres — the foundations PadBridge grew from.

The browser and downloads

  • WebKit and JavaScriptCore — the browser engine.
  • uBlock Origin by Raymond Hill and contributors, with EasyList and EasyPrivacy — ad and tracker blocking.
  • FFmpeg, OpenSSL, curl, libpng, libxml2, HarfBuzz, FreeType, ICU, Skia and SQLite.
  • Mesa (RADV) and the PS5 Vulkan work that brings the GPU to homebrew.
  • yt-dlp — downloads from most video sites.
  • PS5 Java 25 port by mateo-cogeanu, on OpenJDK — JDownloader 2 runs on the PS5 because of this port.
  • JDownloader 2 — a separate program with its own terms. Setup uses your own copy; it is not included.

Building for the PS5

  • PS5 Payload SDK by John Törnblom, and the PacBrew sysroot.
  • ShadowMountPlus and kstuff — required on your console, and not part of Omnibloom.

Fonts and art

  • Inter and Rajdhani, plus Noto Sans CJK, Noto Color Emoji and DejaVu — under the SIL Open Font License and the DejaVu licence.
  • Kenney's input prompts, cursors and crosshairs (CC0).
  • The Omnibloom swirl and flower — the project author's own artwork. The universes, icons and interface were made for this project.
