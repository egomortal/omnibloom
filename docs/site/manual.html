GET STARTED

From PC to sofa.

Use the Setup package that matches the release and your supported console environment.

  1. Read the release notes and supported firmware list. If your configuration is absent, stop and ask the project maintainers.
  2. Open Omnibloom Setup on your PC. Put the PC and console on your trusted home network.
  3. Use Find your PS5, or enter its address. Confirm the selected device before continuing.
  4. Review the checks. Resolve any red result before installing; save the check details for support.
  5. Choose apps. Bloom Core is required while other suite apps remain installed. Downloads and USB Files are selectable parts of the suite.
  6. Review the JDownloader 2 step. It is an optional, separate program; review its installer and licence before choosing it.
  7. Start installation and keep both devices available until Setup reports completion. Do not treat a partially completed progress bar as success.
  8. Open Omni on the console. Use the controller hints and choose a universe.

Update or repair

In Setup, open Installed apps and choose Update for a newer version or Repair for missing application files. Review the selected app and result. Keep your existing data and backups.

The release owner must supply verified package links, checksums, prerequisites and rollback instructions before this guide is published.

Questions, answered.

Does it replace the console system?

No. Omnibloom is a set of homebrew apps. Setup manages suite components; it is not a system update.

Will every streaming site work?

No. Browser compatibility varies. Protected media can require a supported content decryption module and service approval. Omnibloom does not bypass DRM.

Do I need Bloom Core open?

Bloom Core runs in the background. Apps should still open with their own defaults if it is unavailable; shared discovery and actions may be limited.

Can I use another controller?

Check the controller table for the exact model, connection type and verified release. A family name alone is not a compatibility guarantee.

Why is a local page blocked?

The console block limits which local services web content can reach. Installed app pages are allowed only through verified app records. Do not disable the block to fix a page.

Is JDownloader 2 included?

Setup has an optional JDownloader 2 step. Availability and redistribution terms must be checked for the shipped release; it remains a separate project.

Where is Ex-Box 360?

It is planned for later and is not part of this launch promise.

Find the next step.

Setup cannot find the console

Confirm the address and that both devices are on your trusted home network. Run the checks again. Do not change console DNS or firmware as a troubleshooting shortcut.

An app is not running

Open Bloom Core status and note the app version and state. Try the app’s normal Open action once, then save the error for support.

A page will not load

Try a public page you know works. Record the failing address without private query strings. Check date and time if a certificate error appears; never ignore an untrusted certificate.

A download is protected

Use the service’s own supported playback or download option. Protected content is not a retry or downloader-selection problem.

A controller pairs but does not respond

Use the exact model instructions, check connection type and battery, and test another input in Master Control. Save the model and app version; do not repeatedly pair all nearby devices.

The picture or text is clipped

Check the TV’s screen-fit setting, then report the screen resolution and affected page. Keep a screenshot with personal information removed.

A useful support report

Include app version, console firmware, PC operating system, controller model, expected behaviour, actual behaviour and repeatable steps. Redact account names, tokens, cookies and private URLs from logs.

Local app discovery

Bloom Core helps installed apps find each other on the console. Web pages do not receive its token. A verified app record determines which pages the browser can reach.

Sites still receive visits

When you visit a website or start a download, that service receives the request and applies its own privacy policy. A local interface does not make browsing anonymous.

History, saved links and passwords

These features may keep data on the device. Storage, encryption, retention and deletion behaviour must be documented for the final build. Do not publish an encryption or no-telemetry claim until verified.

Support logs

Review logs before sharing them. Remove account details, cookies, tokens, personal file names and private URLs. Sharing a screenshot should be your choice.

Console block

The browser restricts website access to local console services. Ask maintainers to review a legitimate app integration rather than turning off the protection.

Built with others.

Omnibloom stands on open-source work shared by many people. Thank you.

Controllers (Master Control)

  • PadBridge PS5 by X-F1REBALL-X — the payload Master Control starts from.
  • Ghost-Control v5 by StonedModder — the Switch Pro, 8BitDo, Manba, HORI and XIM USB drivers.
  • NikoBellikJR31 — the Manba V2 patch for Ghost-Control.
  • AnyPad-PS5 by elmonomalvad0 and ps5-wireless-pads by AngelLopezTorres — the foundations PadBridge grew from.

The browser and downloads

  • WebKit and JavaScriptCore — the browser engine.
  • uBlock Origin by Raymond Hill and contributors, with EasyList and EasyPrivacy — ad and tracker blocking.
  • FFmpeg, OpenSSL, curl, libpng, libxml2, HarfBuzz, FreeType, ICU, Skia and SQLite.
  • Mesa (RADV) and the PS5 Vulkan work that brings the GPU to homebrew.
  • yt-dlp — downloads from most video sites.
  • PS5 Java 25 port by mateo-cogeanu, on OpenJDK — JDownloader 2 runs on the PS5 because of this port.
  • JDownloader 2 — a separate program with its own terms. Setup uses your own copy; it is not included.

Building for the PS5

  • PS5 Payload SDK by John Törnblom, and the PacBrew sysroot.
  • ShadowMountPlus and kstuff — required on your console, and not part of Omnibloom.

Fonts and art

  • Inter and Rajdhani, plus Noto Sans CJK, Noto Color Emoji and DejaVu — under the SIL Open Font License and the DejaVu licence.
  • Kenney's input prompts, cursors and crosshairs (CC0).
  • The Omnibloom swirl and flower — the project author's own artwork. The universes, icons and interface were made for this project.
