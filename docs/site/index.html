What has been checked?

Local desktop checks now cover Help, loading and error screens, language changes and focus recovery across 47 built-in pages. These checks use controlled examples. They do not confirm every feature on your console.

The PC rig now uses the same WebKit source snapshot as Omni. It completed a bounded 30-minute run with CPU/software rendering. Full Omni patch parity, end-to-end site and add-on checks, and calibration remain open; this run does not predict console performance.

Installation, controller compatibility, native services and final package checks still need release approval. Some bundled components also need licence and attribution issues resolved before distribution. Wait for accepted downloads, checksums and console requirements.

Universe and Sleeve previews

Fifteen Universe start layouts are available as local proposals. Each changes the arrangement and presentation of the same actions. Arrange supports panel swaps with Undo and Reset; a separate Sleeve preview supports custom positions and sizes for the actual Apps, Pins and Recents panels. Native persistence and integration across other app screens remain pending.
