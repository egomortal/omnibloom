# Omnibloom — launch candidate draft

Potential birth from possibility.

Omnibloom brings a controller-first browser, downloads, USB file access and controller tools into one suite. Omni is the browser; Master Control looks after controllers; Bloom Core lets installed apps find each other; Setup guides installation from your PC.

## In this release

- A consistent interface across the suite, with clear controller focus and original universes.
- A guided first run and understandable error pages.
- App discovery and status through Bloom Core.
- Setup screens for installation, updates and repair.

These are release-candidate claims: retain only features verified in the published build.

## Before installing

Read the verified firmware/prerequisite matrix and installation guide supplied with the release. Use the official release package and its published checksums. This draft intentionally has no guessed version number or download link.

## Known limits

Website and controller compatibility varies. Protected streaming and downloads are not bypassed. CPU-rendered browser pages can be expensive. Ex-Box 360 is planned for later. Console validation and the final compatibility matrix are release gates.
