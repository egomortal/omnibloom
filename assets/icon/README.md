# Omni Browser icon

| File | Use |
| --- | --- |
| `omni-icon.webp` | Original full-resolution master (1125×1125, transparent background) |
| `icon0.png` | 512×512 icon for the PS5 homebrew package |
| `omni-icon-{16,32,48,64,128,256}.png` | Resized PNGs for UI, tabs, launchers, and docs |
| `favicon.ico` | Multi-size Windows/web icon (16–256 px) |

To change sizes, regenerate them from `omni-icon.webp`.
