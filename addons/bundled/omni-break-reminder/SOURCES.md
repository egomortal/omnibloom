# Licence and provenance

Original implementation, MIT; no upstream extension code is bundled. Once a minute, the visible tab adds one minute to
a per-day counter in the add-on's own storage when a video / audio element is playing or there was key, pointer or
wheel input in the last two minutes; hidden tabs add nothing. When the chosen number of active minutes has passed
since the last card (and no snooze runs), a small dialog card appears; it only offers OK and "Snooze 15 min" and never
pauses, mutes or closes anything. Nothing is fetched or sent. Checked 2026-11-16.
