# Licence and provenance

Original implementation, MIT; no upstream extension code is bundled. A user-level stylesheet keyed on one root attribute:
`text-decoration: underline` on text links (not on links styled as buttons) and a 4 px yellow `outline` plus a dark halo
on focused links, buttons, form controls and other focusable elements. Nothing is fetched or sent. Checked 2026-11-16.
