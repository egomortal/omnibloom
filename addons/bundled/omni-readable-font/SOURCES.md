# Licence and provenance

Original implementation, MIT; no upstream extension code is bundled and no font is bundled (system faces only: Inter
where installed, Helvetica / Arial, Georgia / Times, Verdana / Trebuchet / Tahoma). A user-level stylesheet keyed on two
root attributes sets `font-family` on text elements (never on icon fonts, `<i>`, code or form controls) and, for the
spacing choices, `line-height`, `letter-spacing` and `word-spacing` on paragraphs and list items. Nothing is fetched or
sent. Checked 2026-11-16.
