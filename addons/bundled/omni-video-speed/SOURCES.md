# Video speed: sources

All code in this add-on is original to Omnibloom (MIT, see LICENSE). It uses no third-party code, fonts or online services.

- `core.js`: playback-rate limits and steps.
- `abloop.js`: the A-B loop state (set A, set B, clear; at B playback jumps back to A). Pure, with no DOM access.
- `controls.js`, `runtime.js`: the panel and controller navigation.
