# Licence and provenance

Original implementation, MIT; no upstream extension code is bundled. Two fixed, click-through shades (pointer-events:
none) dim the window above and below a band at its middle; the band height follows the computed font size / line height
of the element under the window's centre (1.6, 2.4 or 3.6 lines, 24-400 px), re-measured on scroll and resize (one
animation frame each). Nothing is fetched or sent. Checked 2026-11-16.
